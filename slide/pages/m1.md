# 3. The simple Playwright answer

```ts {1-2|4|5-8|9-10|11-13|all}
import { test, expect } from '../helpers/fixtures';

test('traveller searches a one-way flight BKK to SIN', async ({ page }) => {
  await page.goto('/flights');
  await page.getByRole('button', { name: 'One way' }).click();
  await page.getByRole('button', { name: /select origin/i }).click();
  await page.getByRole('button', { name: /Suvarnabhumi/ }).click();
  await page.getByRole('button', { name: /select destination/i }).click();
  await page.getByRole('button', { name: /Singapore Changi/ }).click();
  await page.getByRole('button', { name: /select date/i }).click();
  await page.getByTestId('calendar-panel').getByRole('button', { name: /today/i }).click();
  await page.getByRole('button', { name: 'Search Flights' }).click();
  await expect(page).toHaveURL(/\/flights\/results\/?\?.*origin=BKK.*destination=SIN/);
});
```

<!--
SAY: Build it in layers, click through the highlights. First goto. Then the user actions: click, click. Locators read like what the user sees: a button named "One way". Last, one expectation: we landed on results for BKK to SIN.
`getByRole` finds by what assistive tech sees: the button's accessible name. `fill` types into inputs; here the form is click-based so we click.
DEMO: type the first 4 lines live, run, then add the rest. Instructor note: `helpers/fixtures` is `@playwright/test` plus a small plumbing fixture; we will not touch it.

# Locators: user-facing first

| Priority | Locator | Why |
|---|---|---|
| 1 | `getByRole('button', { name: ... })` | what users and screen readers perceive |
| 2 | `getByLabel('Email')` | form fields by their label |
| 3 | `getByPlaceholder` / `getByText` | visible text |
| 4 | `getByTestId('calendar-panel')` | **fallback** when nothing user-facing exists |

<div class="grid grid-cols-2 gap-6 mt-4">

```ts {all}
// ✗ brittle
page.locator('div > button:nth-child(3)');
page.locator('//*[@id="root"]/a');
```

```ts {all}
// ✓ survives a redesign
page.getByRole('button', { name: 'Search' });
```

</div>

::hint::
`getByRole('button', { name: /select origin/i })`, then `expect(page).toHaveURL(/origin=BKK/)`.

::recap::
- A test is **user steps as code**: `goto`, `click`, `fill`, then `expect`
- Locator order: **role > label > text > test id**. No CSS or XPath.
- `codegen` finds locators; you still write the test
