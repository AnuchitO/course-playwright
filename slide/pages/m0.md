# 3. The simple Playwright answer

```bash {1|2|3|all}
npm init playwright@latest      # your own project
npx playwright install chromium # browsers
npx playwright test             # run
```

```ts {1|3-4|all}
import { test, expect } from '@playwright/test';

test('Qoomlee search page loads', async ({ page }) => {
  await page.goto('http://localhost:3000/flights');
  await expect(page.getByRole('heading', { name: 'Flight Search' })).toBeVisible();
});
```
