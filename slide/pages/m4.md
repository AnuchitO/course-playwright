# 3. The simple solution: look, don't guess

| Need | Tool | Command |
|---|---|---|
| Re-run, watch, time-travel | **UI mode** | `npx playwright test --ui` |
| Step line by line | **Inspector** | `npx playwright test --debug` |
| Post-mortem of a failed run | **Trace Viewer** | `--trace on` then `npx playwright show-trace <trace.zip>` |
| Proof on failure | **screenshot / video** | `use: { screenshot: 'only-on-failure', video: 'retain-on-failure' }` |
| Don't know the locator | **codegen** | `npx playwright codegen <url>` |
| Share the result | **HTML report** | `npx playwright show-report` |

# Two real bugs, found with tools

```ts {1-5|7-14|all}
// Bug 1: Locator never resolved. The trace shows the placeholder on the page:
await page.getByPlaceholder('e.g. Jon').fill('Jane');   // ✗ typo
await page.getByPlaceholder('e.g. John').fill('Jane');  // ✓

// Bug 2: the calendar flashes open, then vanishes. Short screen (600px high):
test.use({ viewport: { width: 1280, height: 600 } });
await page.getByRole('button', { name: /select date/i }).click();
await expect(page.getByTestId('calendar-panel')).toBeVisible();   // ✗ not there
// The app closes the calendar on scroll. Playwright scrolled the button into view.
// Fix: viewport height 1000 (or scroll first, then click).
test.use({ viewport: { width: 1280, height: 1000 } });
```

<!--
SAY: Bug 1 is a typo: the Locator tab in the trace shows what the page had instead. Bug 2 is a real app behavior: the date picker closes itself on scroll. Playwright scrolls an element into view before clicking, the scroll closes the picker, the assertion looks for something already gone. You can see it in the trace's before/after snapshots: that is exactly what the trace is for. No amount of staring at the code finds this.
LAB BRIDGE: they will find both on their own, with tools.
